# Block Crush Daily

A daily block puzzle game with merge power-ups. Fit pieces, clear rows, crush your daily challenge.

## Features
- Daily puzzle challenge (same for everyone, shareable)
- Practice mode with endless random pieces
- Merge power-ups (bomb, hammer, shuffle)
- Rewarded ads for bonus rewards
- No forced ads — opt-in only

Built with vanilla HTML5/JS. Wrapped as Android APK via GitHub Actions.
